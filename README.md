Watch & Earn

A React-based rewards platform concept where users can watch videos, complete activities, track points, and view their earnings through a personal dashboard.

Overview

Watch & Earn explores how a simple rewards platform can work, combining video-based activities with a dashboard for tracking user points and balances.

Features

- User registration and login interfaces
- Personal dashboard with account information
- Video listing and video player
- Reward points for completed videos
- Basic computer-side reward tracking
- Player account balance and earnings display
- Withdrawal request interface
- Separate user and admin routes

Technologies

- React
- JavaScript
- React Router
- CSS3
- Lucide React
- Vite
- Browser localStorage

Getting Started

Clone the repository:

git clone https://github.com/Henrie-x/watch-and-earn.git

Install dependencies:

npm install

Start the development server:

npm run dev

Development Notes

This project currently uses browser localStorage for basic user and reward data. It is a development project, not a production-ready payment or financial service.
